# 🚀 RetroRise

Une plateforme e-commerce moderne pour la vente de sneakers et drops exclusifs.

RetroRise acquiert des marques cultes mais disparues

## 📋 Prérequis

- Node.js (v18+)
- MongoDB
- Docker (optionnel)

## 🚀 Installation

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm start
```
